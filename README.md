# Football Legends

A simple football-themed arcade game made with HTML, CSS, and JavaScript.

## How to play

- Move with WASD
- Tackle with Q
- Blue team attacks to the right
- Red team attacks to the left
- Score by carrying the ball into the opposite end zone

## Run locally

Open `index.html` in a browser, or serve the folder with a simple web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
